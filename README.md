# 桌面问题修复工具

一个双击就能用的 Windows 10/11 桌面问题检查和修复脚本，适合处理以下问题：图标显示成白纸或带黑底、图标错乱、快捷方式失效、桌面图标消失。

## 下载和使用

1. 到 [Releases](../../releases/latest) 下载 `桌面图表修复.bat`，也可以直接下载仓库里的同名文件。
2. 双击运行，按菜单输入序号。
3. 不确定是什么问题时，先选 **[1] 全面诊断**。这一项只检查、不改动任何东西，最后会告诉你该选哪一项。

> 如果 Windows 弹出"Windows 已保护你的电脑"，点"更多信息"→"仍要运行"。这是因为脚本是从网上下载的，并非病毒。

## 功能

| 序号 | 功能 | 适用情况 |
|---|---|---|
| 1 | 全面诊断（只读） | 不知道哪里出了问题 |
| 2 | 清理图标/缩略图缓存 | 白图标、图标后面有黑底、图标错乱 |
| 3 | 处理失效快捷方式和丢失的图标 | 软件卸载后留下的快捷方式、快捷方式全部打不开、文件夹自定义图标丢失 |
| 4 | 恢复桌面图标 | 桌面图标全没了，此电脑/回收站不见了 |
| 5 | 缩略图预览 开启/关闭 | 想让文件夹统一显示普通黄色图标 |
| 6 | 快捷方式小箭头 去除/恢复 | 需要管理员权限，会单独弹出确认 |
| 7 | 「- 快捷方式」后缀 | 以后新建快捷方式不加后缀，或一键去掉现有快捷方式的后缀 |
| 8 | 重启资源管理器 | 桌面卡死、任务栏没反应 |

## 安全说明

- 所有会改动系统的操作都会先询问 Y/N。
- 删除失效的快捷方式时，文件会移到回收站，可以找回。
- 脚本平时以普通权限运行，只有修改系统级设置时才会请求管理员权限。
- 清理缓存和重启资源管理器时，桌面和任务栏会消失几秒，这是正常现象。

## 常见问题

**文件夹图标上叠着一张白纸？**
Windows 会把文件夹里的文件当作预览画在图标上。里面的文件没有关联程序时（比如 `.elf`、`.bin`），就会显示成通用的白纸图标。这属于正常显示，不想看到可以用 [5] 关闭缩略图预览。

**图标后面出现黑色方块？**
这是缩略图缓存损坏。运行 [2] 清理缓存即可。如果经常复发，可以尝试更新显卡驱动。

## 实现

文件外表是 `.bat`，实际逻辑用 PowerShell 编写：批处理部分只负责启动 PowerShell 执行文件本身，这样处理中文路径和注册表更可靠。需要 Windows 10/11 自带的 Windows PowerShell 5.1，无需安装任何东西。
